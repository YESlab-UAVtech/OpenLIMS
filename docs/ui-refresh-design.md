# 前端配色、动效与后台交互优化设计（2026-10-07 已确认 · 三批已施工）

> 用户确认：按三批全部施工；默认预设保持蓝灰色相、只做系统化精修；后台长表单改为右侧滑出抽屉。

> 范围：只改前端表现与交互；路由路径、权限、API、数据库与业务规则不变。四套外观预设（`config/appearance.json`）保留且格式兼容。

## 1. 现状问题（盘点结论）

### 1.1 配色

- 同时存在 4 套互相覆盖的颜色来源：`style.css` 基础变量（默认强调色是金色 `#a16207`）、`theme.css` 写死的通用预设暗色、Vite 注入的预设变量、`admin.css` 独立的 `--admin-*` 调色板；`refinement.css` 另有 `--lab-*` 与首页写死的 `#275cb6`。
- 后果：暗色模式下 `:root[data-theme='dark'] .portal-page--admin`（0,3,0）压过 `presets.css` 的映射（0,2,0），**后台暗色不跟随所选预设**；首页强调色写死为蓝色，学术、工程、生命科学预设在首页失效；危险/成功等状态色在前台与后台各有一套值。
- 约 365 处硬编码色值（`portal.css` 131、`style.css` 84、`theme.css` 66、`admin.css` 52、`refinement.css` 32），派生色（悬停、按下、浅底）手工逐个写，预设之间难以一致。

### 1.2 动效

- 无统一时长与缓动：现有 17 种「时长 + 曲线」组合（120–420ms，`ease` / `ease-out` / 4 种贝塞尔混用）。
- 页面切换无过渡；后台每个页面各自包一层 `PortalShell`，切换模块时整个侧栏、通知中心重新挂载（通知中心每次重新请求并重建轮询），侧栏滚动位置丢失。
- 展开/收起、列表增删各页自定义过渡名（`task-reveal`、`tm-view`、`task-list` 等），部分页面没有过渡；加载态只有「正在读取…」文字，内容到达时整体跳动。

### 1.3 后台交互

- 约 25 处使用浏览器原生 `window.confirm`：样式与站点割裂，不区分危险操作，无法说明后果细节。
- 成功/失败提示固定在页面或表单顶部，长表单滚动后看不到结果。
- 未保存保护只有任务管理有；成员管理切换成员会静默丢弃未保存修改，主页编辑、悬赏、积分表单同样没有保护。
- 成员管理首屏先展示「吉祥物与展示设置」，主流程（找人 → 改资料）被推到下方。
- 公开导航栏对管理员同时渲染 7 个后台直达链接和一个内容相同的「后台管理」下拉菜单。

## 2. 方案

### 2.1 配色：一处定义、语义派生

- 新增 `src/styles/tokens.css`，在 `main.js` 中最先引入，作为唯一语义色板：
  - 表面：`--color-background`、`--color-surface-soft`、`--color-surface-muted`、`--color-card`、`--color-elevated`、`--color-overlay`。
  - 文本：`--color-foreground`、`--color-text-strong`、`--color-text-secondary`、`--color-text-subtle`。
  - 边框：`--color-border-faint`、`--color-border`、`--color-border-strong`。
  - 品牌：`--color-primary`、`--color-primary-fill`、`--color-secondary`、`--color-accent*`、`--color-ring`，并派生 `--color-primary-hover`、`--color-primary-pressed`、`--color-primary-soft`。
  - 状态：`success` / `warning` / `danger` / `info` 各含前景、浅底、边框三档。
  - 阴影与遮罩：按明暗分别定义，暗色用更深的环境阴影加 1px 内描边，而不是加大透明黑。
- 派生色用 `color-mix(in oklab, …)` 由预设核心色自动计算，四套预设自动得到一致的悬停/浅底/边框层级；`appearance.json` 现有键全部保留，新增键可选。
- 删除 `theme.css` 中写死的通用预设暗色、`refinement.css` 首页的 `#275cb6` 覆盖；`--admin-*` 与 `--lab-*` 保留名称但改为指向语义变量，修复后台暗色不跟随预设的问题。
- 逐文件把硬编码色值替换为语义变量；保留的例外仅限：品牌 Logo / 证书预览的白色画布、3D 模型与插图自带颜色。
- 验收：四预设 × 明暗，正文 4.5:1、控件边界 3:1。

### 2.2 动效：统一节奏，只动 transform / opacity

- 动效变量：`--duration-instant 90ms`、`--duration-fast 140ms`、`--duration-base 200ms`、`--duration-slow 280ms`；`--ease-out cubic-bezier(.22,1,.36,1)`、`--ease-in-out cubic-bezier(.65,0,.35,1)`、`--ease-emphasized cubic-bezier(.2,0,0,1)`。现有过渡统一改用变量。
- 共享过渡类：`fade`、`rise`（淡入 + 6px 上移）、`reveal`（`grid-template-rows: 0fr → 1fr` 展开，不动 `height`）、`list`（`TransitionGroup` 增删 + `move`）、`dialog`、`toast`。各页自定义过渡名改为共享类。
- 路由过渡：公开页 / 成员系统使用 `rise`（200ms）；后台改为**持久外殼**（见 2.3），只有内容区过渡，侧栏与通知中心不再重新挂载。
- 骨架屏：列表与详情加载时显示与最终布局同尺寸的骨架，避免内容到达时跳动。
- 全部动效遵守 `prefers-reduced-motion: reduce`（降为即时切换或纯淡入），页面隐藏时暂停循环动画（现有规则保留）。

### 2.3 后台：通用交互基建

- **持久外壳**：`/admin/*` 路由改为嵌套在一个 `AdminLayout` 下，路径不变；`PortalShell` 检测到外层已有后台布局时只渲染标题与内容。侧栏当前模块高亮、桌面端可收起为图标栏（偏好存 `localStorage`），顶栏显示「模块 / 子页面」面包屑。
- **确认对话框** `ConfirmDialog` + `useConfirm()`：返回 Promise，可传标题、后果说明、危险等级、确认按钮文案；焦点陷阱、Esc 取消、默认焦点落在「取消」。替换全部 `window.confirm`（含成员系统页面，保证全站一致）。
- **全局提示** `ToastHost` + `useToast()`：右下角（手机为底部）堆叠，成功 4 秒自动消失，错误需手动关闭，`aria-live` 播报；表单字段级错误仍就地显示。
- **未保存保护** `useUnsavedGuard(dirty)`：切换条目、离开路由、关闭页面时提示；接入成员、主页编辑、悬赏、积分、新手任务、成果审核表单。
- **侧滑抽屉** `AdminDrawer`：创建/编辑类长表单从右侧滑出（桌面宽 `min(760px, 100vw - 72px)`，手机全屏），列表保持可见与滚动位置；头部固定标题与关闭，底部固定操作栏（取消 / 保存，含未保存提示）；关闭前走未保存保护，Esc 与遮罩点击可关闭，焦点进入抽屉并在关闭后回到触发按钮。
- **吸底保存条**：非抽屉的长表单（成员资料、主页编辑）有修改时出现「有未保存修改 · 放弃 / 保存」，替代滚到底部才能看到的保存按钮。

### 2.4 后台：逐页流程调整

| 页面                           | 调整                                                                                                                                                                                                       |
| ------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 成员管理                       | 新增学生管理员改为抽屉；吉祥物设置移到页尾可折叠的「展示设置」区；成员列表吸顶、显示筛选计数、支持键盘上下切换；切换成员前未保存保护；资料表单吸底保存条；重置密码移入「账号安全」折叠区并改用确认对话框。 |

| 任务管理 / 新手任务 / 任务进度 | 新建/编辑任务改为抽屉，列表与筛选保持可见；统一使用通用确认、提示；进度页逐人明细支持按状态筛选、审核表单就地展开动画。                                                                                    |
| 积分管理                       | 规则说明折叠为提示条；发放表单与流水左右分栏，发放成功后流水新条目高亮插入；冲正改用确认对话框。                                                                                                           |

- 公开导航：管理员只保留「后台管理」一个入口（下拉菜单），移除重复的 7 个直达链接。

2. **后台逐页**：按 2.4 表格逐页改造，并替换全部 `window.confirm`。

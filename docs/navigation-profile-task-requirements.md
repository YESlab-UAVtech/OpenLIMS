## 2. 待审核的具体口径

- 合并后的成员入口统一命名“个人主页”，以 `/profile` 为主地址；登录后进入此页，旧 `/today` 链接兼容跳转。
- 页面从上到下为：问候及今日概览、待办与个人日程、成员档案与编辑入口、积分热力图、可接悬赏、账号设置。今日原有任务进度、等待审核、近七天日程和悬赏推荐继续可用；两周积分小图由完整热力图统一表达。
- 热力图沿用公开成员详情的可见资格：能查看该成员公开主页的人（包括未登录访客）能查看每日积分和积分总数；未公开成员继续不可访问。教师是否参与积分展示沿用既有口径，不新增排名资格。
- 公开热力图只展示每日汇总和总分，不公开积分流水原因、操作者、内部编号、本人待办、账号设置或个人日程。
- 后台三类任务共用“任务管理”标题、说明、分类导航和侧栏选中状态；新手设置与审核、悬赏编辑与接取名单/履约入口完整保留。
- 删除的是后台独立悬赏管理入口；成员端“悬赏榜”继续保留。
